# 問い合わせ管理システム 運用手順書

作成: 田中(情報システム)  最終更新: 2026-05-12

## 1. 構成

| 役割 | ホスト名 | OS | 備考 |
|---|---|---|---|
| Web サーバ | hk-web01 | Ubuntu 22.04 | Nginx + PHP 8.2(PHP-FPM) |
| DB サーバ | hk-db02 | Ubuntu 22.04 | MySQL 8.0 |

- Web サーバ上のサイト: 問い合わせ管理(`inquiry.`)、会社サイト(`www.`)、社内掲示板(`board.`)
- アプリの置き場所: `/var/www/inquiry/`(`public/` が公開領域)
- 添付ファイルの保存先: `/var/www/inquiry/files`

## 2. 日次・定期処理

- **バックアップ**: 毎晩 1:00 に DB サーバで MySQL のダンプを取得(`/var/backups/mysql/`)
- **夜間集計**: 毎朝 2:30 に Web サーバで集計を実行し、結果を総務の佐藤さんにメールで送る(佐藤さんが毎朝確認している)
- **ログ回転**: 毎週日曜の早朝に logrotate(Nginx のログを 4 世代保持)

## 3. セキュリティ方針

- SSH は鍵認証のみ。パスワードログインは使わない
- DB の管理用アカウントは個人名義で作成し、退職時に削除する
- アプリの設定ファイル(`config.php`)は第三者に読ませない

## 4. 更新作業の基本

1. 作業前に DB をダンプして別の場所へ退避する
2. 業務時間外(20:00 以降)に実施する
3. 更新後、トップ・一覧・検索・集計の各画面が表示されることを確認する

## 5. 連絡先

- 情報システム: 後任未着任(2026-10 現在、総務の佐藤さんが兼務)
